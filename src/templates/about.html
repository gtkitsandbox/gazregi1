About {{ site.config.site_name }}

{{ site.config.site_name }} is an independent search and discovery layer over official government Gazette publications. It is not affiliated with, endorsed by or operated by any government.

{{ page_visual("about") }}

What the index contains

This build is configured for {{ stats.countries }} countries; {{ stats.with_records }} currently have published records. It holds {{ stats.issues }} verified Gazette issues and {{ stats.pages }} searchable pages, plus {{ stats.records }} structured records that have passed source-excerpt validation. {{ stats.people }} person identities are operator-verified and published. Coverage is incomplete and is not a complete record of any country's gazette.

Every indexed page preserves the Gazette number, publication date, physical PDF page, printed page where available, source filename, source checksum and official document URL where recorded. Original PDFs are not hosted here; links point to the official publisher when a verified URL is available.

How records are published

  1. The official PDF is extracted with PyMuPDF into page-level NDJSON and compressed source text.
  2. A structured record stores a verbatim source excerpt and the exact PDF page.
  3. The build rejects the record if the excerpt is not present in the extracted page text.
  4. The source document checksum is checked against the extraction provenance registry.
  5. Names and organisations are linked only through explicit operator-maintained identifiers, never through automatic name matching.

Summaries and keywords are editorial aids only. Dates, numbers, positions, organisations and references are taken from the cited source excerpt.

People and identity

A person page is a navigation layer, not a biography. It contains only the published name, operator-verified name variants, official positions and the Gazette records that support them. It does not contain contact details, family relationships, estimated assets, political views or speculative relationships.

Two people with the same or similar published name are kept separate unless an operator explicitly verifies that they are the same identity. When a name is shared, each identity page links to the other with a disambiguation notice. Unverified identity mappings are held out of the public index.

Limitations

  • Page text is extracted automatically and can contain OCR or layout artefacts. The official PDF remains authoritative.
  • Not every Gazette page has been split into notice-level records. Unstructured pages remain searchable as page records.
  • Official PDF URLs are shown only when recorded; an absent URL is displayed as not recorded rather than guessed.
  • Closing dates and tender details are published as stated in the Gazette. Verify them with the issuing organisation before relying on them.
  • This site does not provide legal, procurement or financial advice.

Accounts, tracking and submissions

There are no user accounts, saved searches, alerts, payments or tender submissions. The site does not load advertising or analytics scripts. Search runs in the browser against a prebuilt Pagefind index.

Correction requests are described on the corrections page. Source documents remain with their official publisher.

Country coverage

The architecture is country-independent. {{ stats.countries }} countries are configured under data/<country-code>/; {{ stats.with_records }} have published records and the remainder show a truthful empty-coverage state. Configured countries are {{ country_names }}. Adding a country does not change the templates or URL structure for existing records.
